# QuestHouse — Telegram Mini App

Мини-приложение для бота [@QuestHouseBookingBot](https://t.me/QuestHouseBookingBot).

- **Брони** — лента дней, сетка сеансов: нажал на свободное время → бронь создана в 1 клик, детали можно дописать.
- **Касса** — касса-отчёт за день по своим полям (приход/расход), итог, отправка отчёта в любой чат.
- **Настройки** — комнаты/квесты, время сеансов, цена и гости по умолчанию, поля касса-отчёта.

Данные хранятся в облаке Telegram (CloudStorage) — привязаны к аккаунту пользователя, видны с любого устройства.

Всё приложение — один файл `index.html`, сервер не нужен.
